# fiat penus

*let there be provisions* — a household's lists, notes wall and photo board
for Sailfish OS, and a native client for
[Pantry](https://github.com/chenasraf/nextcloud-pantry), the household app for
Nextcloud.

- A household on the phone itself, with lists, notes and photos, that needs no
  account; Nextcloud households come alongside it when you connect
- Sign in with Nextcloud Login Flow v2, or with an app password made by hand
- Households: switch between them, start a new one, see who is in it
- Lists: grouped by category, quantities, notes, pictures, items that come back
  (every N days, weeks, months or years, on schedule or counted from when done),
  items that leave the list when ticked off; uncheck all, clear what is done
- The notes wall: cards in the household's colours, pinned first, Markdown
- The photo board: folders, a grid, swipe through, captions, upload from Gallery
- The last copy of every list, wall and board stays on the phone for offline reading
- The cover shows what is left on the list last looked at

Sharing requires a Nextcloud server with the Pantry app installed. Written against
Pantry's OpenAPI description (server 0.37).

Part of the fiat family — small, focused Sailfish OS apps that do one thing
plainly. Not made by or affiliated with the Pantry project.
